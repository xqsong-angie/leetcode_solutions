## 💡 如何高效刷题？

1. **先学基础，再做题目**：做每个类型前，先了解该数据结构或算法的基本概念。
2. **5 分钟思考原则**：每道题先独立思考 5 分钟，如果没有思路，不要死磕，立即看讲解或视频学习解题技巧。
3. **记录错题与卡点**：使用 `❌`（毫无思路/看题解）、`🙂`（整体思路正确但未能自行修正所有 Bug）、`✅`（独立一次性 AC）标记题目。
4. **针对性消灭 🙂 和 ❌**：不断重做 `🙂` 和 `❌` 的题目，直到能做到独立完整写出 Bug-free 的代码！
