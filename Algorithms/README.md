## 💡 How to Approach Each Category

1. **Understand the Pattern First**: Read basic theory or watch a tutorial before solving questions blindly.
2. **5-Minute Rule**: Spend 5 minutes thinking about the approach. If you're completely blocked, watch/read the explanation right away to learn the trick.
3. **Track Your Bugs**: Mark each question with `❌` (stuck/tutorial needed), `🙂` (minor bug/edge cases failed), or `✅` (fully accepted).
4. **Iterate & Refine**: Re-do all `🙂` and `❌` problems until you can implement them bug-free!
