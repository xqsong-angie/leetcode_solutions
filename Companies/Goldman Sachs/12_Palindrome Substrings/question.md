Given a string, find the count of all substrings of the string that are palindromes.

**Note:** A palindrome is a string that reads the same from the first character to the last and from the last character to the first.

**Example 1**
Input: s = "abcbd"
Output: 6
Explanation: The palindromic substrings of the string s are "a," "b," "c," "b," "d," and "bcb."

**Example 2**
Input: s = "abdaa"
Output: 6
Explanation: The palindromic substrings of the string s are "a," "b," "d," "a," "a," and "aa."

**Constraints**

* 1 <= |s| <= 2000
* It is guaranteed that the string s consists of lowercase English letters.
